Koda Library — Phase 0 hand test

This page runs the real Phase 0 code — the same files the automated tests check — so you can try it yourself. There is no app screen for Phase 0; this is the screen.

1 · Tiles — what a learner spells with

English spells in letters. Khmer spells in clusters: a base consonant with the subscripts under it is one tile, and every vowel sign is a tile of its own. Try ស្វាយ, ស្ត្រី (two subscripts on one base), or a word that cannot be drawn.

2 · Split a story, and blank a word

Paste a story. It becomes sentences and words. For Khmer the words are only a proposal from the browser's breaker — look for one that joined two words. A space you type forces a break.

3 · Check a story

The eight checks a story must pass before anyone is asked to publish it. Pick a starter story, then press a Break it button and watch exactly one rule turn red. You can also edit the JSON by hand.

4 · Spell it — the deck from the story above

Each spelling question becomes the story sentence with a blank, and a ring of tiles. Tap tiles in order, then check. A story that cannot be played shows the error instead.
