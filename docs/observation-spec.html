A real game with a learning spine

The child arrives at a named place, checks the target tray, searches one lively illustrated scene, and taps every matching object in any order.

Every level uses the same ObjectHunt engine. The child experiences a polished game; controlled difficulty, hints, telemetry, and practice make it an Observation skill.

Game-first presentation. Edge-to-edge place art, passive motion, tactile finds, short arrival transitions, success sounds, and satisfying completion—without coins, energy, ads, lives, or punitive timers.

Game-screen rules

  • Any order: no target is artificially active.
  • Persistent evidence: unfound objects use 85% opacity and found objects return to 100%, without rings or ticks.
  • Gentle mistakes: wrong taps preserve scene progress.
  • Touch floor: every effective area is at least 44×44 pixels.
  • Mobile first: scene and five-card tray fit at 360×640.
  • Accessible route: List view offers labelled candidate cards.

Try it: find the shell, crab, and ball.

Required audio—not optional polish

Chimes and recorded reactions are sequenced, never overlapped. Draft development may use live TTS for requested prompts; publication requires bundled recordings and an Observation voice plan reporting zero missing clips.

Clean UI chimes

A partial match plays pop. A final match plays success; a wrong tap plays error. Each recorded reaction starts only after its chime ends.

100 object prompts

Recorded “Find the {object}” prompt for every canonical object name, used by Read Aloud and target preview.

11 lesson introductions

Each place/lesson audioPrompt is collected from lessons.json and recorded under audio/lessons/.

Correct reactions

At least five variants, including “Congratulations! You found them all!”

Incorrect reactions

At least four gentle variants, including “Not a match. Try again.”

Fixed phrases

Scanning help, four region hints, and already-found feedback.

The activity uses only koda.sound, koda.haptics, and koda.speech. It never calls new Audio(), browser speech, or the clip registry directly.

Structure follows the reference skill

The executable structure mirrors src/skills/counting/: flat skill art, recursive recorded audio, JSON lessons/manifest, one index entrypoint, and inherited tests.

One engine

ObjectHunt.tsx implements exact, silhouette, near-decoy, rotation, scale, occlusion, clutter, and mixed modes. JSON selects the mode.

Original place-based art

Exactly 100 bundled object SVGs and 20 scene SVGs live directly in assets/, matching the existing ./assets/*.svg registration.

One scene = one question

Wrong taps are attempts; subtargets are local progress; the final target submits correct and advances.

Skill contract

This application skill uses manifest.json, lessons.json, index.ts, activity code, voice registration, and tests. It does not invent a second runtime SKILL.md format.
